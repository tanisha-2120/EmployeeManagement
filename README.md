# Employee Management System

## Project Description

Employee Management System is a simple web-based application developed using HTML, CSS and JavaScript.

The system helps users manage employee records by providing basic operations such as adding, displaying, searching, updating and deleting employee information.

## Features

- Add Employee
- Display Employee Details
- Search Employee
- Update Employee
- Delete Employee

## Employee Information

The system stores the following employee details:

- Employee ID
- Employee Name
- Email
- Department
- Designation
- Salary

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Git Branching Strategy

The project uses the following branches:

- main
- develop
- feature/add-employee
- feature/search-employee
- feature/update-employee
- feature/delete-employee

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in a web browser.
4. Add employee details.
5. Use the search, update and delete operations.

## Git Workflow

Feature branches are created from the develop branch.

Completed features are merged into the develop branch.

After testing and verification, develop is merged into the main branch.
